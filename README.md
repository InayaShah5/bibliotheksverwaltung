# Bibliotheksverwaltung

Eine Python-Anwendung zur Verwaltung von Büchern mit JSON-Datenspeicherung.

## Funktionen

- Bücher hinzufügen
- Alle Bücher anzeigen
- Bücher suchen
- Bücher ausleihen
- Bücher zurückgeben
- Verfügbarkeit von Büchern anzeigen
- Daten dauerhaft in einer JSON-Datei speichern
- Eingaben überprüfen und Fehler behandeln

## Technologien

- Python
- JSON
- Datei-Verarbeitung
- Funktionen
- Listen und Dictionaries

## Verwendung

Das Programm wird über das Terminal gestartet:

```bash
python library_management.py
